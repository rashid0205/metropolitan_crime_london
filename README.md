# Metropolitan Crime London
---
This repository contains the data, code, and supporting materials for the paper Metropolitan Crime London (2010-2026), which has been accepted for publication in Computational Urban Science. The repository provides the resources required to reproduce the analyses, visualisations, and findings presented in the paper, supporting transparency, reproducibility, and future research on crime patterns and urban dynamics in London.

In order to run this code, follow the steps below.

- Upload the `base_dir` to Google Drive
- Add the Jupyter notebook to Google Colab
- Edit the `base_dir` string in the notebook to be the path of your `base_dir`
- Add two empty directiries to the `base_dir` called `clean_data` and `models`
- Connect to a `v5e01 TPU`-type runtime (available with the free version)
- Run all
